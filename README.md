# react-dashboard-ui

> Admin dashboard UI built with React 18 and TypeScript

A clean, dark-themed admin dashboard with sidebar navigation, KPI cards, and activity feed. Zero UI library dependencies — pure React + CSS.

## Stack

- **React 18** + **TypeScript**
- **Vite** for dev/build
- Custom CSS (no Tailwind, no component libs)

## Features

- Sidebar navigation with active state
- Stats cards with trend indicators
- Activity feed with color-coded event types
- Responsive layout

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173
